## Attachments and alt text

For one image, use note search. For a short sequence, attach context, saved, search and duplicate in that order. All seven PNGs are 1280 × 720; the light image is an alternative to the dark saved image.

1. [01-context.png](../demo/01-context.png): SourceSpool's organize screen shows the Field notes collection, tags light and reference, the note "Look at the reflections," and a destination filename preview.
2. [02-review.png](../demo/02-review.png): The review screen shows a local sample URL, MP4 format, tags, note and destination path before saving.
3. [03-saved.png](../demo/03-saved.png): SourceSpool confirms the sample was saved, showing its relative path, 77,086 verified bytes and a SHA-256 hash prefix.
4. [04-search.png](../demo/04-search.png): Searching for "reflections" returns prism-study with tags light and reference because the word appears in its saved note.
5. [05-duplicate.png](../demo/05-duplicate.png): SourceSpool offers K to keep an existing source/format reference or N to save another with a unique filename.
6. [06-export.png](../demo/06-export.png): SourceSpool confirms a catalogue metadata export and explains that media files need a separate backup.

[03-saved-light.png](../demo/03-saved-light.png): A light rendering of the same saved confirmation, relative path, verified byte count and hash prefix.

The [30-second video](../demo/sourcespool-demo.mp4) is also included in the ZIP.

These are annotated renders of captured production Ink text using an original local sample. Keep the version heading and capture footer visible. Five-second video holds are editorial timing. The assets demonstrate the library workflow; first-run installation and external-site compatibility require separate evidence. [Capture details](../demo/README.md).
