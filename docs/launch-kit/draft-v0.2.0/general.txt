I’ve released SourceSpool v0.2.0, a Windows terminal library for saved video and audio references.

You can now launch it with:
npx sourcespool

Or install it permanently:
npm install -g sourcespool
sourcespool

Keep a source link with each item, add tags and notes, and find it later. Collections, filename previews, duplicate choices and metadata import/export are included.

Requires Windows 11 x64 and Node 24 (24.19.0 or later in the Node 24 line). First run reuses working tools or offers verified yt-dlp/FFmpeg setup. Fresh tools download about 133 MB; existing verified downloads can be reused offline.

The app is MIT licensed; external tools retain their own licenses. Inspired by Yoinks. Existing workflow images use original local samples captured in v0.1.0 and illustrate the library, not the new installation flow. Metadata exports do not include media files.
