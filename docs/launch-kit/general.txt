SourceSpool v0.2.0 is available on npm: a Windows terminal library for saved video and audio references.

Try it:
npx sourcespool@latest

Or install it permanently:
npm install -g sourcespool
sourcespool

Keep the source link with each item, add tags and notes, and search them later. Organize collections, preview filenames before saving, choose what to do with duplicates, and import/export catalogue metadata. Media files need their own backup.

Requires Windows 11 x64, local NTFS storage and Node >=24.19.0 <25. First launch reuses working tools or offers yt-dlp/FFmpeg setup.

The app is MIT licensed; external tools retain their licenses. Inspired by Yoinks. The workflow images show an original local sample captured from the v0.2.0 checkout.
