I built SourceSpool, a Windows terminal app for organizing saved video and audio references.

Keep a source link with each item, add tags and notes, and search them later. It also has collections, filename previews, duplicate prompts and metadata import/export.

v0.1.0 is open source under MIT. This is a source release for Windows 11 x64 and requires Node 24, yt-dlp and FFmpeg.

Inspired by Yoinks. The attached images show captured production terminal output using an original local sample.
