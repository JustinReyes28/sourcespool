I’ve released SourceSpool v0.2.0 with npm installation.

Run npx sourcespool to launch it, or npm install -g sourcespool for a permanent installation. It requires Windows 11 x64 and Node 24, starting at 24.19.0.

SourceSpool keeps the context with a saved media reference: source URL, collection, tags and notes. Search those details later, review filenames before saving, choose what to do with duplicates, and import/export catalogue metadata. Media files need their own backup.

First run checks existing tools and offers verified yt-dlp/FFmpeg setup if needed. Fresh tools download about 133 MB; existing verified downloads can be reused without another transfer. Setup and app updates preserve the separate media library.

The app is MIT licensed; external tools retain their licenses. Yoinks inspired the terminal workflow. The code and sample media are original. Attached historical v0.1.0 captures use a locally served sample and illustrate the library workflow, not the npm installation screens or external-site compatibility.
